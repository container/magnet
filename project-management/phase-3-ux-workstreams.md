# Phase 3 UX Workstreams

Purpose: concise UX task categories for Phase III.

Status: working note

---

## 1. Website IA

Finalize the website information architecture and use the public prototype to validate navigation, page types, content hierarchy, rental entry points, event discovery, spaces and programmes/community.

## 2. Platform Scope And Prioritization

Use the admin prototype plus a prepared list of functions, modules and integrations to facilitate prioritization. Output: MVP / later / external integration / out-of-scope matrix.

## 3. User Groups, Roles And Access

Validate the existing role/access specification through workshop edge cases. Cafe/info-point staff belong here as a user group/role to define.

## 4. User Journeys

Treat user journeys as a standalone required output and as a tool for scope decisions. For each journey, identify whether it needs public content, platform functionality, admin workflow or integration support.

## 5. Integrations

Inspect required integrations more closely. Define expected outcomes, data flows and ownership boundaries while leaving provider/implementation choices open where appropriate.

## 6. Operations, Ownership And Procurement Readiness

For each module or function, define daily operational ownership, transition-period needs before platform launch, procurement criteria, and open decisions that affect the next tender/specification.
