## 2. Phase III Role Context

The user's role in Phase III is UX designer / UX nacrtovalec.

UX designer responsibilities captured from the role slide:

- scope definition: determine platform boundaries, including what is included and excluded, based on user needs
- information architecture: create the sitemap and define content groups and page types
- user scenarios: describe core usage scenarios and user journeys on the platform
- operational process design: define processes the platform must support, such as reservations, sales and event management
- prioritization: prepare functionality lists with proposed priority, minimal scope and development phasing
- access logic: design user types, roles and permission matrix from the UX perspective
- page and content-section design: define required pages and content sections
- platform functionality definition: list and briefly describe the functions the platform must include, grounded in user needs and stakeholder requirements
